# ingestion-index-anchored
Index anchored ingestion artifacts through derived embedding services.

------------------------------------------------------------------------
## Inputs
- `ingestion_id`: ingestion identifier whose anchored artifacts should be indexed.
- `indexing_run_id`: ingestion-owned indexing run identifier to update.

------------------------------------------------------------------------
## Output
A summary containing the indexed source, chunk, embedding, and failure counts.
